Question Wise Solutions

Question 1 (3 Marks)

Q: If sin x = 3/5, x lies in second quadrant, then find the value of other five trigonometric functions?

Solution:

Since x is in Quadrant II, sin x and cosec x are positive, while cos x, sec x, tan x, cot x are negative.

  • sin x = 3/5
  • cosec x = 1 / sin x = 5/3
  • cos x = -√(1 - sin² x) = -√(1 - 9/25) = -√(16/25) = -4/5
  • sec x = 1 / cos x = -5/4
  • tan x = sin x / cos x = (3/5) / (-4/5) = -3/4
  • cot x = 1 / tan x = -4/3

Question 2 (3 Marks)

Q: Convert (a) 40° 20' into radian measure (b) -4 radian into degree measure (use π = 22/7).

Solution:

(a) 40° 20' to Radians:

20' = (20/60)° = (1/3)° ⇒ 40° 20' = (40 + 1/3)° = (121/3)°

Radian measure = (121/3) × (π / 180) = (121π / 540) radians

(b) -4 radians to Degrees:

Degree measure = -4 × (180 / π) = -4 × 180 × (7 / 22) = -2520 / 11 degrees

-2520 / 11 = -229° and 1/11°

(1/11) × 60' = 5' and 5/11' ; (5/11) × 60" ≈ 27"

Result = -229° 5' 27" (approx.)


Question 3 (3 Marks)

Q: The minute hand of a watch is 1.5 cm long. Find the distance covered by its tip in 45 minutes.

Solution:

Radius (r) = 1.5 cm

Angle rotated in 60 minutes = 360° = 2π radians

Angle in 45 minutes (θ) = (45 / 60) × 2π = (3/4) × 2π = 3π/2 radians

Distance covered (l) = r × θ = 1.5 × (3π / 2) = 1.5 × 1.5 × π = 2.25π cm

Using π ≈ 3.14: Distance = 2.25 × 3.14 = 7.065 cm (or 9π/4 cm)


Question 4 (3 Marks)

Q: Find the value of (a) sin 315° (b) cos 15°.

Solution:

(a) sin 315°:

sin (360° - 45°) = -sin 45° = -1 / √2

(b) cos 15°:

cos (45° - 30°) = cos 45° cos 30° + sin 45° sin 30°

= (1 / √2)(√3 / 2) + (1 / √2)(1 / 2) = (√3 + 1) / (2√2)


Question 5 (3 Marks)

Q: Prove that cot²(π/6) + cosec(5π/6) + 3 tan²(π/6) = 6.

Solution:

LHS = cot²(π/6) + cosec(5π/6) + 3 tan²(π/6)

  • cot(π/6) = √3 ⇒ cot²(π/6) = (√3)² = 3
  • cosec(5π/6) = cosec(π - π/6) = cosec(π/6) = 2
  • tan(π/6) = 1/√3 ⇒ tan²(π/6) = (1/√3)² = 1/3

LHS = 3 + 2 + 3 × (1/3) = 3 + 2 + 1 = 6 = RHS. Hence proved.


Question 6 (3 Marks)

Q: Prove that (sin x - sin 3x) / (sin² x - cos² x) = 2 sin x.

Solution:

Numerator = sin x - sin 3x = -(sin 3x - sin x) = - [2 cos((3x + x)/2) sin((3x - x)/2)] = -2 cos 2x sin x

Denominator = sin² x - cos² x = -(cos² x - sin² x) = -cos 2x

LHS = (-2 cos 2x sin x) / (-cos 2x) = 2 sin x = RHS. Hence proved.


Question 7 (3 Marks)

Q: Show that tan 3x tan 2x tan x = tan 3x - tan 2x - tan x.

Solution:

We know that 3x = 2x + x

Taking tan on both sides:

tan 3x = tan(2x + x) = (tan 2x + tan x) / (1 - tan 2x tan x)

Cross multiplying:

tan 3x (1 - tan 2x tan x) = tan 2x + tan x

tan 3x - tan 3x tan 2x tan x = tan 2x + tan x

Rearranging the terms:

tan 3x tan 2x tan x = tan 3x - tan 2x - tan x. Hence proved.


Question 8 (2 Marks)

Q: Prove that cos 24° + cos 55° + cos 125° + cos 204° + cos 300° = 1/2.

Solution:

  • cos 204° = cos(180° + 24°) = -cos 24°
  • cos 125° = cos(180° - 55°) = -cos 55°
  • cos 300° = cos(360° - 60°) = cos 60° = 1/2

LHS = cos 24° + cos 55° + (-cos 55°) + (-cos 24°) + cos 300°

LHS = (cos 24° - cos 24°) + (cos 55° - cos 55°) + 1/2 = 0 + 0 + 1/2 = 1/2 = RHS.


Question 9 (2 Marks)

Q: If cos x = -4/5 and x ∈ [0, π], find the value of cos(x/2)?

Solution:

Since x ∈ [0, π], x/2 lies in [0, π/2], which means x/2 is in Quadrant I (where cos(x/2) > 0).

Formula: cos²(x/2) = (1 + cos x) / 2

cos²(x/2) = (1 + (-4/5)) / 2 = (1 - 4/5) / 2 = (1/5) / 2 = 1/10

cos(x/2) = √(1/10) = 1 / √10
